# Frontend Review Skill

## Checklist

1. Перевірити семантику HTML та обов'язкові атрибути (lang, alt, meta viewport).
2. Перевірити наявність медіа-запитів (@media) для мобільних екранів у CSS.
3. Перевірити відсутність синтаксичних помилок у JavaScript.
4. Перевірити форматування згідно з .prettierrc.json.
